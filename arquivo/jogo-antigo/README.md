# Jogo antigo arquivado

Esta pasta guarda as páginas de entrada da versão anterior do Sistema Solar.

A experiência principal é agora a versão Paper em `paper-preview/` e arranca com:

```powershell
npm run dev
```

Para consultar deliberadamente a versão antiga:

```powershell
npm run dev:archive
```

Os diretórios `src/`, `styles/` e `public/` permanecem na raiz porque contêm módulos científicos e recursos ainda reutilizados pela experiência Paper e pela suite histórica de testes. Não são a entrada padrão da aplicação.
